# 11 API: requirements

- R1. `api.main:app` (FastAPI). Run with `uv run uvicorn api.main:app --port 8000`. The model and replay index load once at startup from `models/`; if the model files are missing the app starts and `/health` reports `model_loaded: false` with the command that creates them.
- R2. `GET /health` → status, model version (git commit from `model_meta.json`), classes, and whether replays are available.
- R3. `GET /runs` → `models/replays/index.json`; `GET /runs/{run_id}` → that replay JSON; unknown id → 404 with a plain message. The run id is validated against the index (no path traversal).
- R4. `POST /predict` body (pydantic): either `rows` (list of raw readings, each an object of channel name → value plus `t` in seconds, time-ordered, one run) or `reading` (one raw reading) with `load_percent` optional. Response: class probabilities for the last row, predicted class, alarm state over the window using the exported alarm settings (for `rows` only), `mode` ("window" or "steady-state"), and warnings (missing channels filled how, window shorter than 15 minutes, steady-state assumption).
- R5. Missing required channels → 422 listing them. Unknown channels are ignored with a warning. Channels excluded from the model (dPf, dPex, engine room temperature, time columns) are ignored silently if sent.
- R6. `POST /explain`: same body; response adds grouped SHAP (five sensor groups) for the predicted class and for every class, the top 8 features with value and SHAP, source channel and group for each, and the base value. Additivity holds (grouped sum plus base equals the model margin for that class within 1e-4; tested).
- R7. `GET /whatif/baselines` → per load bin (40/60/75/85) the median healthy reading of every model input channel, plus a short list of "slider" channels with sensible ranges (5th to 95th percentile over all healthy and faulty rows at that load): charge air pressure, charge air temperature after cooler, turbine inlet and outlet temperatures, the three cylinder exhaust temperatures, fresh cooling water pressure, engine cooling water flow, fuel flow. Built at export time into `models/whatif_baselines.json` from the clean table (healthy rows only for medians).
- R8. CORS allows the web dev server (`http://localhost:5173`) and a configurable origin via `KEYFRAME_CORS_ORIGINS`.
- R9. Latency: a test builds a 15-minute window from a real replay-like input and asserts `/predict` plus `/explain` for one row complete in under 300 ms each on this machine (median of 10 calls after one warm-up), and records the numbers in `reports/results/11_latency.csv`. If over budget, profile and fix in the service (for example compute rolling features only for the last row).
- R10. No model retraining and no score changes (ADR 0009).
