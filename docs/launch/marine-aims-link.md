---

> **Successor: [Keyframe](https://github.com/MrNahadi/KeyFrame).** Marine AIMS was trained on a synthetic engine dataset whose sensors are independent noise with faults added as fixed offsets, so its scores say little about a real engine. Keyframe rebuilds the same idea on real test-bench data from a marine diesel, scores every model on an engine load it never trained on, and checks its explanations against the engine physics. This repository stays up as the earlier version.
